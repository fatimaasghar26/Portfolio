#  Fatima Asghar — Personal Portfolio

A clean, responsive personal portfolio website built entirely with vanilla HTML5 and CSS3 — no frameworks, no build tools, no dependencies.

**🔗 Live site:** [fatimaasghar26.github.io/Portfolio](https://fatimaasghar26.github.io/Portfolio/)

## 📋 Overview

This repository contains the source code for my personal portfolio — a single-page site showcasing who I am, what I know, what I've built, and how to reach me. It's designed to be lightweight, fast-loading, and easy to maintain without relying on any external libraries or frameworks.

## ✨ Features

- **Fully responsive** — adapts smoothly across desktop, tablet, and mobile using Flexbox and CSS Grid
- **Zero dependencies** — no frameworks, no npm packages, no build step required
- **Sectioned layout** — Home, About, Skills, Projects, and Contact, each with its own clear structure
- **Interactive project table** — lists current projects with tech stack, status, and direct links
- **Quick-contact actions** — one-click Email and WhatsApp buttons, with a clipboard-copy fallback if a mail client isn't available
- **Scroll-reveal animations** — subtle fade/slide-in effects as sections enter the viewport (respects `prefers-reduced-motion` for accessibility)
- **Downloadable CV** — direct download link to a PDF résumé

## 🛠 Tech Stack

| Category | Details |
|---|---|
| Markup | HTML5 (semantic elements) |
| Styling | CSS3, CSS Custom Properties (variables), Flexbox, Grid |
| Interactivity | JavaScript (IntersectionObserver, Clipboard API) |
| Hosting | GitHub Pages |

## 🚀 Getting Started

No installation, no dependencies — just open it.

**Option 1: View it live**
Visit [fatimaasghar26.github.io/Portfolio](https://fatimaasghar26.github.io/Portfolio/)

**Option 2: Run it locally**
```bash
git clone https://github.com/fatimaasghar26/Portfolio.git
cd Portfolio
```
Then simply open `index.html` in any browser — no server or build step needed.
